# 环境兼容性

本技能是 Markdown 指令，无固定模型、CLI、API Key 或其他技能依赖。以下是能力适配设计，不代表已经完成各平台实测。

| 可用能力 | 行为与局限 |
|----------|------------|
| 文件读取、写入和执行工具 | 可检查项目、保存路线、实现核心并实际验证；遵循当前项目授权和规则 |
| 只有聊天或只读能力 | 分析用户提供的材料，在回复中交付路线；不声称已写入或已运行 |
| 没有联网 | 使用已有证据，标注无法核实的外部事实及其影响；必要时把核实列为前置任务 |
| 没有运行环境或测试数据 | 给出可复现验证步骤，结果标为未验证；不能因工具缺失认定路径成立 |
| 接手端未安装技能 | 使用路线内完整接手约定，无需读取技能或原始对话 |
| 不支持 disable-model-invocation | 按 description 和正文保持明确调用语义；平台是否能阻止自动路由需实测 |
| 没有子智能体 | 日常使用无影响；维护时只能做串行或内联健全性检查，不能冒充独立对照 |

显式调用可通过平台的技能选择方式，或要求模型读取本 SKILL.md。安装及自动发现机制由平台决定；本技能不检测模型是否足够强，也不自动选择执行模型。

维护用 `evals/evals.json` 为合成情境，用于观察行为；同模型对照不能证明不同能力模型接手效果或真实额度节省。实际测试状态以评测记录为准。
