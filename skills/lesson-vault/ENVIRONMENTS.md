# 环境兼容性说明

## Claude Code（完整支持）
读写双端全功能：沉淀、检索、主动建议、指针询问。测试经独立子 agent 验证（lesson-vault-workspace/iteration-1、iteration-2，共 14+14 断言）。

## Claude.ai（部分支持）
- 本技能为纯指令型（无 scripts、无子 agent 依赖），核心读写双端完整可用。
- 测试 harness 的子 agent 对跑不可用：改为串行自评（由当前会话直接执行技能并自检）。
- 无浏览器：跳过 eval 查看器，评分结果直接在对话中展示。

## Codex / OpenCode 等其他 agent
- SKILL.md 为平台无关的纯指令，任何能读写项目文件的 agent 都可执行（读端+写端均不依赖 Claude 特有工具）。
- 未安装本技能的 agent 对经验库的发现依赖规则文件指针（首次落盘后经用户同意写入 CLAUDE.md/AGENTS.md 一行）。

## 必需工具
- 无（纯指令）。写端需要项目 `docs/` 的写入权限。

## 优雅降级
- 无写入权限：条目作为回复正文输出，并说明"未能落盘，请手动保存"，不假装已写入。
- 项目为非 git 目录：条目照常落盘，是否版本化由项目自身决定。
- 用户未同意写指针：经验库照常工作，但未安装本技能的 agent 发现率下降——简报中会提醒。
