# PDF 输出指南

报告写完 Markdown 后，用 `scripts/md_to_pdf.py` 转排版精美的 PDF。

## 转换流程

1. **完成 Markdown 稿件**：标准 Markdown，保存为 `[研究对象]_横纵分析报告.md`
2. **装依赖**（如未装）：`pip install weasyprint markdown`
3. **运行**：
   ```bash
   python [skill目录]/scripts/md_to_pdf.py input.md output.pdf --title "研究对象名称" --author "研究者"
   ```
4. 脚本自动生成中间 HTML（便于调试）和最终 PDF

> **无 WeasyPrint 时降级**：只交付 Markdown，向用户说明"未安装 WeasyPrint，本次只交付 Markdown，装依赖后可补出 PDF"。不要因缺依赖卡住交付。

## 脚本内置排版规范

`md_to_pdf.py` 已内置完整 CSS，无需手动调：

- **页面**：A4，页边距上 25mm / 左右 20mm / 下 20mm
- **封面页**：自动生成，含标题（28pt 深蓝）、副标题"横纵分析法深度研究报告"、作者、装饰分隔线
- **配色**：H1=#1a5276 深蓝、H2=#1e8449 绿、H3=#2e86c1 浅蓝、H4=#5b2c6f 紫、正文=#2c3e50 深灰
- **字体**：fallback 链 `"Droid Sans Fallback", Helvetica, Arial, sans-serif`，自动处理中英混排
- **正文**：10.5pt，行距 1.75，两端对齐，孤行/寡行控制
- **引用块**：左侧 3pt 深蓝竖线 + 浅灰背景
- **表格**：全宽、深蓝表头白字、斑马纹行
- **页眉**：「报告标题 | 横纵分析法深度研究报告」（首页不显示）
- **页脚**：「第 X 页」（首页不显示）
- Markdown 第一个 H1 自动提取为封面标题，正文不重复出现

## Markdown 写法（让脚本正确解析）

- 第一行用 `# 标题` 作为报告标题（自动用于封面）
- 紧接标题用 `> 研究截止时间：YYYY-MM-DD | 所属领域：... | 研究对象类型：...` 写元信息行（会被提取到封面）
- 用 `##` 作主要章节、`###`/`####` 作子章节
- 表格用标准 Markdown 表格语法
- 引用用 `>`，加粗用 `**文本**`

## 报告结构模板（对应 SKILL.md 输出顺序）

```
# [研究对象] 横纵分析报告
> 研究截止时间：YYYY-MM-DD（执行当天） | 所属领域：... | 研究对象类型：...

## 一、核心结论
[3-5 句：它是什么 + 最关键判断]

## 二、关键时间线
[纵向核心节点压缩成可扫读时间线]

## 三、横向对比表
[统一维度的对比表，结构化]

## 四、详细分析
### 4.1 纵向分析：从诞生到当下
[完整纵向叙事，6000-15000 字，含路径依赖/能力/包袱收口]
### 4.2 横向分析：竞争图谱
[横向展开，3000-10000 字，含选择 vs 放弃收口]
### 4.3 横纵交汇
[交叉分析 + 未来 3 路径，1500-3000 字]

## 五、未来判断
[3 条路径 + 各自前提 + 预警信号]

## 六、仍待确认的问题
[本研究没核实清楚的问题清单]

## 信息来源
[所有引用来源 + URL + 访问时间]

## 方法论说明
[横纵分析法来源，1-2 句]
```
