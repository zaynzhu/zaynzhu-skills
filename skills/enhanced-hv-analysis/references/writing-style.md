# 写作风格指南

这不是一份冷冰冰的咨询报告，而是一篇让人能从头读到尾的深度研究。在"研究报告的严谨"和"可读性"之间找平衡。

## 核心风格元素

**节奏感**：句子时长时短，段落之间跳跃自然。不要每段都一样长，一句话自成一段制造重量感可以用。好的节奏像波动，每次围绕主线偏出去一点，再用一句"扣主线句"拉回来。

**叙事驱动，不是罗列驱动**：纵向部分要有故事弧线，有起承转合。比如一个产品为什么在某个时间点突然爆发，背后的铺垫是什么，转折是什么。不要写成"2023年1月发布了A，2023年3月发布了B"这种流水账。

**知识是"聊着聊着顺手掏出来"的**：在讲述过程中自然带出背景知识，不要"下面我来给大家科普一下"。

**敢下判断**：鼓励给观点和洞察，但每个观点必须有事实支撑。先摆事实，再给判断。是推测的明确标注"据此推断"，观点用"我的判断是 / 我认为"承认主观性，而不是居高临下的定论。（这是本增强版证据规则 3 的写作体现。）

**层层剥开的修辞**：不直接讲结论，用"现象→表面解释→更深的追问→核心洞察"展开。让读者参与到思考过程中。

**文化升维**：在交汇洞察部分，连接到更大的文化/哲学/历史参照物。不是硬凑的升华，是"聊着聊着自然想到了"的感觉。

**回环呼应**：开头或纵向部分埋的细节和钩子，在交汇洞察或结尾 callback 回来。前后因果的闭合感，是让报告从"信息流"变成"作品"的关键。

## 需克制的元素

- **过强的口语化**：报告可以有聊天感，但不要满篇"这玩意""不是哥们""太牛逼了"。偶尔点缀可以，密度要比公众号低很多。
- **去小标题化**：公众号追求一口气顺下来不加小标题。研究报告 1-3 万字没有清晰结构会迷路，**需要清晰的章节结构**。
- **标点禁令可以放松**：报告可正常使用冒号和破折号（信息传达效率），但""的使用习惯可保留。
- **固定尾部**：不要加公众号三连/星标尾部。

## 绝对禁区（无论什么文体都避免）

- 套话："首先...其次...最后"、"综上所述"、"值得注意的是"、"不难发现"
- 空洞形容词："赋能"、"抓手"、"打造闭环"
- 教科书开头："在当今AI快速发展的时代"、"随着技术的不断进步"
- 高频踩雷词："说白了"、"意味着什么？"、"这意味着"、"本质上"、"换句话说"、"不可否认"
- 空泛工具名：不说"AI工具"、"某个模型"，要说具体名字
- 编造场景：搜不到的信息诚实标注"该信息暂未核实"，绝不编造

## 用人话写

避免咨询公司式套话和空洞概括。用具体细节和例子代替概括性陈述。
- 不要写："该公司在这一阶段实现了快速增长"
- 要写："从2024年中期的1000万美元ARR到2025年底的10亿美元，增长曲线几乎是垂直的"

## 与证据规则的配合

写作风格服从证据规则（见 SKILL.md）：
- 写事实时就近标 `[来源，日期]`
- 写推断时前缀"据此推断"
- 写观点时前缀"我的判断是 / 我认为"
- 遇冲突并列两个说法 + 各自来源
- 搜不到写"暂未核实"，不拿记忆充数
