# 溯源手册：场景手法 · 后端矩阵 · 查询模板

## 通用溯源三步

1. **找"据谁说"**：转述页里的"据 X 报道 / 来源：X / 据 X 通报"——X 就是上一个节点。
2. **上溯到一手**：X 不是一手（官方公告/当事方声明/原始数据/论文原文）就继续沿引用链上溯；追到头就是源头，追不到头就如实说"未能溯源到一手"。
3. **判独立性**：各转述是否同一出处（判定标准见 source-grading.md）。

## 场景 A：品牌/产品

1. 先做官方域名发现（official-domain-discovery.md）。
2. **参数/价格/政策以官网为准**；第三方价格只当参考并标注级别。
3. 渠道真伪：以官网的"官方渠道/授权店铺"页为准；电商"官方旗舰店"也要与官网互链核对（假旗舰店存在）。
4. 中文陷阱：搜"XX 官网"的前排常被代理商/加盟站/假官网占据——这正是必须走域名发现、不能信排名的原因。

## 场景 B：新闻/事件

1. **首发优先序**：官方通报（政府/警方/监管/公司公告）> 当事方原始声明（官方账号原帖）> 首发媒体署名报道 > 其他（全是转载）。
2. **时间锚定**：用 `--start-date/--end-date`（Tavily）把窗口缩到事件发生日附近找首发；对比各源发布时间，最早的未必是首发（也可能是编造），要与官方渠道互证。
3. **以讹传讹识别**：拿首发版本与流行版本逐点对比——数字走样、细节增删、主体偷换、"网传"表述；用转述中**独有的细节句**反搜，定位最早出现的版本。
4. 冲突时并列：首发说什么、流行版本说什么、差异在哪，不悄悄选边。

## 场景 C：技术资料

1. 文档：官方文档域（docs.xx.com）+ **版本锚点**（旧版页面常被当成现行规范引用）；changelog / release notes 读原文。
2. 论文：arXiv / DOI / 出版社页读原文；**引用数是流行度不是正确性**；预印本要标注"未经同行评审"。
3. GitHub：官方 org vs 第三方 fork/镜像；README 指向的官网要过域名发现。

## 后端选择矩阵（backend-agnostic）

| 生态 × 类型 | 首选 | 次选 | 备注 |
|-------------|------|------|------|
| 中文品牌/新闻 | 浏览器 MCP（百度/微信搜一搜/微博） | Tavily + `--include-domains` | Tavily 中文索引弱；内置 WebSearch 偏英文源 |
| 英文品牌/新闻 | Tavily（news 模式 + time-range） | WebSearch + WebFetch | |
| 中英混合 | 按信息点拆开，各落中文/英文行；品牌/实体用官方名与当地名各搜一次 | WebFetch Wikidata 拿官方名 | 别把混合查询塞进同一次搜索 |
| 技术文档 | Tavily `--include-domains` 官方域 | WebFetch 直抓官方域 | |
| 结构化实体 | WebFetch Wikidata API | — | 不花搜索额度 |
| 封闭生态全文（公众号等） | 浏览器 MCP（搜一搜） | 官方渠道直接打开 | 无工具则明示覆盖不到 |

降级链：首选不可用 → 次选；全部不可用 → SKILL.md 的降级策略（手动验证指南）。

**付费墙/登录墙**：WebFetch 拿到的墙外内容（标题/摘要）不可当正文证据——标"正文未核"，改用该媒体官方账号自述、权威转载或存档页；中文封闭生态同理。

**频率纪律**：一切外部 API/搜索调用间隔 ≥2 秒。

## 查询模板

| 目的 | 模板 |
|------|------|
| 官方直达 | `<品牌> official site` / `<品牌> 官网`；找到域名后 `--include-domains <官方域>` |
| 首发定位 | `<事件> 通报 OR 声明 OR 公告 OR 官方`；行政事件加 `site:gov.cn` |
| 引用追查 | `"<转述中独有的细节原句>"`（精确匹配反搜最早出处） |
| 转载识别 | `"<特征句>"` 命中多站同文 → 内容农场/同源转载 |
| 时间窗口 | `--start-date <事件日> --end-date <事件日+3>` 锁首发 |

## 执行器映射

| 动作 | 用什么 |
|------|--------|
| 裸搜索 | enhanced-tavily-search 脚本（`--include-domains/--exclude-domains/--min-score/--start-date/--end-date`）或内置 WebSearch |
| 直抓页面 | WebFetch（官网直达、页面本体深检、Wikidata API） |
| 封闭生态/反查 | 浏览器 MCP（百度/微信搜一搜/微博、以图搜图） |
