# 垃圾与可疑信号清单（GEO / SEO / 内容农场）

本清单供 source-first 第二步「搜索与结果快筛」使用。原则：**信号是概率，不是判决**——单个弱信号只降级，多个强信号才丢弃；任何处置都要能在输出里向用户说清理由。

## 用法

- **快筛层**（零额外成本）：只看搜索结果元数据（域名/标题/snippet/平台），对全部结果过一遍。
- **深检层**（触发式）：结果需要采用但快筛发现可疑信号 → WebFetch 页面本体再查一遍。

---

## 快筛层信号

### 域名信号

| 信号 | 例子 | 置信 |
|------|------|------|
| 品牌精确匹配 + 怪后缀 | brand-vipshop.com、nike-store-sale.top | 高（假官网重灾区） |
| 连字符堆砌 + 关键词堆砌 | best-cheap-running-shoes-reviews-2026.com | 高 |
| 廉价后缀承载商业内容 | .top/.xyz/.info/.cyou 上的购物/测评站 | 中 |
| 站群同模板 | 同一模板、同一联系方式、互链的多域名 | 高 |
| 与官方域名近似 | typosquatting（go0gle、openai-offical） | 高 |

### 标题信号

- "Best X of 2026 / X 大推荐 / 排行榜 / 避坑指南"列表农场标题 → 中
- 标题精确复读 query 关键词（SEO 堆砌特征）→ 中
- 夸张/恐慌/悬念标题（"震惊""99% 的人不知道""紧急提醒"）→ 中
- 无作者、无日期的"资讯"标题 → 弱

### snippet 信号

- snippet 精确复读 query → 中
- snippet 承诺的内容与标题/正文明显不符 → 中
- snippet 给出具体数字但无出处 → 中

### 平台信号（中文生态 P0）

- 百家号/搜狐号/网易号营销号洗稿 → 中（只能当线索）
- 小红书种草文伪装"真实评测" → 中
- CSDN/知乎营销软文（文末带课程/推广）→ 中
- 公众号标题党 + 导流 → 中
- 问答区自问自答（同一套路复制多个问题页）→ 高

## 深检层信号（WebFetch 页面本体）

1. **无作者/无发布日期**，或日期可疑（大批量同日发布）；
2. **AI 模板文特征**：结构高度模板化（每段一个加粗小标题）、泛泛而谈无具体细节、结尾"总之/综上所述"、配图全是 stock 图、同站多篇文章句式雷同；
3. **互抄检测**：取文中一个特征句再搜一次，≥3 个不同"站点"同文 → 内容农场实锤；
4. **带货/导流密度**：链接大量指向电商或导流页、带 affiliate 参数；
5. **GEO 特征**：权威口吻但统计数字无出处、引用列表伪造或打不开、Q&A 段堆砌长尾关键词；
6. **中文特有**：经营性内容站无 ICP 备案、备案主体与站点名义不符、whois 新注册（< 6 个月）却自称"老牌"。

---

## 处置规则

| 命中情况 | 处置 |
|----------|------|
| 快筛命中 ≥1 个高置信信号 | 不采用；输出中一句话说明原因 |
| 快筛命中 ≥2 个中置信信号 | 深检；深检不过就不采用 |
| 仅 1 个中置信信号 | 可用，但按"普通媒体"或"UGC"级别对待，关键信息须交叉验证 |
| 深检命中互抄/伪造引用 | 整域降为"可疑农场"，本会话内不再使用该域 |
| 官方域名命中弱信号 | 仍要深检——官方页面也可能被克隆/仿冒，域名对 ≠ 页面对 |
