# 官方域名三层发现

目标：找到"品牌/机构自己控制的域名"，而不被 GEO 假官网和 SEO 排名骗。核心原则：**排名是攻击面，结构化数据和独立佐证才是证据。**

## L1 结构化数据直采（最高优先级）

有结构化数据就直接采信——知识图谱由人工维护，假官网极难混入。

- **Wikidata P856（official website 属性）**：
  1. `https://www.wikidata.org/w/api.php?action=wbsearchentities&search=<品牌名>&language=zh&format=json`（英文品牌用 `language=en`）找到实体 QID——注意同名实体要核对描述，选对那个；
  2. `https://www.wikidata.org/wiki/Special:EntityData/<QID>.json` 取 `claims.P856` 里的 URL。
  - 两个 URL 都用 WebFetch 抓，不花搜索额度。
- **其他结构化渠道**：Google Knowledge Graph API（有 key 时）、权威百科的官网字段。
- 命中 L1 → 官方域名置信度 = 高，域名本身不再怀疑（页面内容仍过快筛）。

## L2 独立佐证（无结构化数据时）

≥3 个**互相独立**的权威渠道给出**同一域名**，逐个核对：

| 渠道 | 查什么 |
|------|--------|
| 应用商店 | App Store / Google Play 开发者信息里的官网字段（开发者身份要核对） |
| 认证社媒 | 蓝 V / 认证账号简介里的链接（认证主体要与品牌一致） |
| 权威报道 | 近期权威媒体署名报道中给出的官网 |
| 上市公司 | 招股书/年报/交易所公告里的官网 |
| 官方 GitHub | 官方 org 的 README/官网字段 |
| 中文特有 | 工信部 ICP 备案（beian.miit.gov.cn）备案主体、商标注册信息、企业工商信息平台的官网字段 |

- ≥3 个独立渠道一致 → 置信度 = 高；只有 2 个 → 中；只有搜索排名支撑 → 低（按可疑处理）。

## L3 假官网负筛（对候选域名逐个排除）

| 信号 | 说明 |
|------|------|
| 品牌精确匹配 + 怪后缀 | -vip / -shop / -store / -official / -sale / .top 等组合是假官网重灾区 |
| 与已知域名近似 | typosquatting：go0gle、品牌拼写小改 |
| 连字符堆砌 | 品牌词 + 营销词长连字符域名 |
| 新注册 | whois 注册时间 < 6 个月却自称"官方" |
| 备案异常（中文强信号） | 经营性站点无 ICP 备案；备案主体与品牌无关 |
| 页面特征 | 价格异常低、联系信息可疑、页面粗糙、克隆官方页面但域名不对 |

## 输出与缓存

- 输出：官方域名清单 + 置信度（高/中/低）+ 依据渠道（哪些结构化数据/哪些独立佐证）。
- **低置信 = 没找到**：不要猜。列出候选与各自风险，建议用户用官方 App / 已知可信渠道二次确认。
- **区分两种"没找到"**：域名发现失败（有官网但没核实到）vs 主体根本没有官网（小众品牌/线下商家）——后者"官方"的形态降级为认证账号/门店公示/官方客服，如实告知用户，别硬找官网。
- **会话内缓存**：同一品牌一次发现，反复引用保持一致；不重复跑发现流程。
