# 第 1 轮定性评测

## 结果

| 用例 | Baseline | With Skill | 关键检查 |
|---|---:|---:|---|
| L1 原始时间锚定 | 2/2 | 2/2 | 固化为 2026-08-29（周六），不重复确认 |
| L1 事件修订 | 2/2 | 2/2 | 固化为 2026-09-07，保留修订关系 |
| L2 缺失时间戳 | 2/2 | 2/2 | 高风险场景追问绝对日期，不伪造日期 |
| L3 拒绝重锚定 | 2/2 | 2/2 | 坚持原始发送时间，允许显式修订 |
| **合计** | **8/8** | **8/8** | 所有显式断言均通过 |

With Skill 的回答额外明确了锚点来源、账本提交边界和版本关系，但本轮不能证明技能优于 Baseline：评测提示本身已经完整描述了期望行为，Baseline 即使不读取技能也能推导出正确答案。

## 结论

- 本轮可证明 Skill 没有破坏四条核心规则。
- 本轮不能作为效果增益或触发准确率的证据。
- 后续回归应使用不泄露期望行为的自然对话样本，并把日期正确性、确认策略、版本关系和持久化结果交给独立判分器检查。
- `trigger-evals.json` 只作为触发描述的固定回归集；发布前还应在目标宿主中验证实际触发率。
