# 环境兼容性

| 环境能力 | 可完成工作 | 不能声称的结果 |
|---|---|---|
| Codex / Claude Code / OpenCode，有文件与云端 CLI/API 权限 | 侦察、改文件、触发并跟踪云端构建、下载和检查产物 | 没有运行证据时不能称已验证 |
| 只有文件与 shell，无云端账号 | 完成 Dockerfile、Compose、workflow、说明与静态检查 | 不能构建，不自动回退本地 |
| 对话环境，无文件/执行工具 | 基于用户提供的脱敏结构给可保存文件和云端执行步骤；缺源码时明确假设 | 不能称文件已落盘或云端已运行 |
| 有已授权远端构建机 | 在确认远端身份后完成构建和烟测 | 用户本机 self-hosted runner 不算云端 |
| 用户明确选择本地 Docker | 检查已有引擎、Buildx、Compose，按相同验收链路本地执行 | “已装 Docker”不等于本地执行授权 |

基本依赖：可读取项目和写文件的工具；完整执行需要一个获准的云端构建环境和上传/运行/下载权限。离线包路径不要求镜像仓库账号。本机无需 Docker、Podman、语言运行时或构建 SDK。

平台的 action 版本、runner 架构、额度和 artifact 限制随时间变化，实现时核对实际可用能力。缺工具就保留可用产物并提供下一步，不虚构兼容性。技能自身没有外部 API 脚本；实际生成的轮询/请求脚本仍须落实至少 2 秒请求间隔及退避。
