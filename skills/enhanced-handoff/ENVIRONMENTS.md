# 环境兼容性说明

## 运行要求

本技能是 Markdown 工作流，无脚本、网络 API、模型 API Key 或固定 CLI 依赖。生成者需要能读取当前上下文；保存文件需要目标目录写入权限。读取项目与 Git 能力用于核对，不是纯分析交接的前置条件。

## 按能力适配

| 环境／能力 | 行为 | 验证边界 |
|-------------|------|----------|
| Codex、Claude Code、zcode 等具有文件工具的 agent | 安装机制由工具决定；加载 SKILL.md 后可生成／接收文档 | 不保证各平台自动发现、工具权限或模型行为一致；尚需真实平台试用 |
| 接收端没有安装 skill | 用户让其读取交接文档，按文档内接手约定继续 | 不依赖 Skill 工具或生成端的私有上下文 |
| 双方均未安装 | 生成端可手动读取本 SKILL.md；已有交接文档可直接使用 | 不会自动触发未安装技能 |
| 没有 shell／Git | 使用文件读取能力；版本状态无法核对时明确说明 | 不虚构分支、提交或测试结果 |
| 只有聊天能力或目录不可写 | 在回复中输出完整 Markdown 与建议路径，由用户转交 | 明确尚未保存；不能宣称自动落盘或同步 |
| 只读审查 | 读取获准材料，回复审查及交回摘要 | 未获文档写入授权时不回写文件 |
| 缺少可选工具／图像能力／联网 | 用真正等价的能力；否则记录缺口或阻塞 | 不用文字推测冒充视觉或真实运行验证 |

## 维护时的测试

`evals/evals.json` 提供合成场景；独立会话可比较有技能与普通交接基线，并检查无技能接手者的行为。同模型独立会话测试只能证明这些样本中的行为，不代表 GPT、GLM 等不同模型或各客户端已经验证。

描述触发查询位于 `evals/trigger-evals.json`。未运行平台真实路由测试前，不宣称触发准确率。测试记录与反馈查看页放独立工作区，不随技能日常加载。
