# Enhanced Neat Freak 变更日志

## 迭代 1（2026-06-18）

### 失败的测试用例

- 暂无自动运行结果；本轮为初版创建，先提供 L1/L2/L3 评测用例。

### 具体修改

- 新增 `SKILL.md`：定义知识库同步的五种工作模式、证据账本、最小同步流程、反膨胀规则和交付格式。
- 新增 `references/upgrade-notes.md`：说明相对本地 `neat-freak` 的增强点。
- 新增 `references/change-impact-matrix.md`：把变更类型映射到 README、docs、项目级指令和记忆层。
- 新增 `references/audit-checklist.md`：作为交付前自审门禁。
- 新增 `evals/evals.json`：覆盖正常同步、只审计、歧义输入和危险删除。
- 新增 `ENVIRONMENTS.md`：说明 Claude Code、Codex、OpenCode、OpenClaw 和无 shell 环境下的行为。

### 预期效果

- 新技能比旧版更适合在真实仓库中做最小必要同步。
- 面对歧义或危险请求时优先审计和建立证据，不直接大范围修改。
- 对不能写记忆的环境有明确降级方式。

## 迭代 2（2026-06-18）

### 失败的测试用例

- 本地触发评测发现：`整理一下` 如果无开发或文档上下文，可能被误解为普通文件整理，不应无条件触发知识库同步技能。

### 具体修改

- `SKILL.md` frontmatter：将 `整理一下`、`梳理一下` 收窄为"已有开发、文档、交接或项目收尾上下文"中的触发词。
- `SKILL.md` frontmatter：明确普通文件整理、桌面/下载目录整理和系统磁盘清理不触发。

### 预期效果

- 保留阶段收尾时的短语触发能力。
- 降低普通文件整理场景的误触发概率。

## 迭代 3（2026-09-14）

### 缺陷依据

- 用户实测增量同步漏掉已删除残片目录与失真的主模型快照；记忆层被以“最近更新过”判为 keep。

### 具体修改

- 恢复强制第零步尺寸体检、第一步记忆机械式全量枚举和逐文件逐条审查；增加绝对时间、描述一致性、自然失效、跨文件矛盾与覆盖对账门禁。
- 范围收窄只适用于项目 docs 扫描深度，受限项不得冒充完整审查。
- 同作用域 CLAUDE.md / AGENTS.md 默认全文一致，处理缺失配对、别名和工具专属规则；无法裁定的分歧询问用户。
- 同步参考清单、影响矩阵、环境说明和使用文档，新增评测 5–8 覆盖上述回归与权限边界。

### 验证边界

- 评测定义不代表真实平台端到端执行通过；本轮进行静态结构检查与场景审查，不修改真实记忆或声称其他机器已同步。

- 实际检查：Markdown 主文件行数与资源引用、8 个评测定义 JSON、项目规则逐字节一致性、git diff --check 均通过；临时合成目录验证枚举命令覆盖隐藏/忽略/孤立文件（6/6）。
- 独立静态场景审查：用例 5–8 未发现阻塞问题；按审查建议补充内容指纹对账，防止只比总数漏掉同名内容变动。未运行完整模型行为基准或真实平台 E2E。
