# Fact-Check — 事实核查

## 一句话

拿一个说法（观点/结论/数据/方案），拆成「可验事实 / 推出的结论 / 价值判断」三层；事实联网核查来源/样本/时间/上下文标 5 级；再假设事实成立审推理链（能否推出、隐藏假设、相关 vs 因果、遗漏解释、成立失效条件）；最后输出四件套：可信/需修正、最关键漏洞、补强后最合理版本、可相信到什么程度。

## 设计理念

AI 有幻觉，人类的幻觉往往更大——"AI 帮人走上愚昧之巅"。一个自信的说法，无论 AI 还是人说的，背后常常是：事实微妙地错/脱离上下文，或事实全对但结论推不出来。

底色是**笛卡尔式怀疑**：先怀疑，再按"证据 + 推理"决定相信到什么程度。不判对错，给**校准过的置信度**——在什么条件下可相信、能信几分。

核心信念：**核查 ≠ 判对错。核查 = 拆开说法、分别验其真假与推理、告诉你能信到什么程度。**

关键洞察：大多数幻觉不是凭空捏造，而是两种——事实层（真但被夸大/脱离上下文）+ 推理层（事实全对但结论推不出来，人拿真事实拼假结论）。所以攻两层：先验事实，再**假设事实全对**单独审推理。

## 触发方式

说以下任意一句即可触发：

- "事实核查 / 核查一下这个说法"
- "这个说法对不对 / 这个观点靠谱吗"
- "验证一下这个数据/结论 / 帮我查证"
- "fact-check / 这个说法有没有根据"
- "这段话哪里有问题 / 这个数据准吗 / 这个结论成立吗"

即使用户只是贴了段话/数据/观点问"这是真的吗""靠谱吗""有问题吗"，也应触发。

**关键区分**：讲懂概念 → dual-layer-explanation；系统研究出报告 → enhanced-hv-analysis；红队找弱点 → adversarial-review；正反论证一个想法/决定做决策 → steel-man；验一个说法/数据/结论的真假+推理 → 本技能。

## 工作流程

### 1. 拆成三层
- **可外部验证的事实** → 联网核查
- **从事实推出的结论** → 推理链检查
- **价值判断** → 不验真假，识别其基于什么标准

方案同理：前提=事实，"方案会 work"=结论，优先级=价值。

### 2. 事实核查（联网为主，无网降级）
查来源/样本/时间/上下文，逐条标 5 级：
1. **已证实**：多来源一致、一手、样本充分、时间对、上下文完整
2. **基本成立需收窄**：核心真但范围/程度/时间被夸大（最常见）→ 给收窄范围
3. **存在争议**：有可靠反证/来源分歧 → 并列各方
4. **证据不足**：找不到足够证据也无明确反证 → 不默认假
5. **明显错误**：可靠来源直接反驳 → 给反证

纪律：一手来源优先、数据查口径、冲突并列、搜不到标"证据不足/未能核实"不编造。**无网时事实全标"未能联网核实"，推理链照做并声明假设事实成立。**

### 3. 推理链检查（假设事实成立）
1. 事实能否推出结论（逻辑必然/合理推断/跳跃）
2. 藏没藏未经验证的假设
3. 是否混淆相关与因果
4. 是否遗漏其他解释或关键信息
5. 结论在什么条件下成立或失效

### 4. 输出四件套
1. **事实可信度**：逐条带 5 级 + 需修正的给修正
2. **推理链最关键漏洞**：1-2 个最致命的，指在哪一跳
3. **补强后最合理版本**：证据和推理都站得住的重述
4. **可相信到什么程度**：条件式校准——"在 X 条件下可相信 Y，否则只能信 Z/不可信"

## 力度控制

- 默认：全流程，5 级 + 推理 5 项 + 四件套，最大怀疑
- `--quick`：只核 2-3 个关键事实 + 1 个最关键漏洞 + 置信度
- `--deep`：每事实展开来源比对，推理每项详写（重要决策前严查）

## 与同类技能的区分

| 技能 | 做什么 | 何时用 |
|------|--------|--------|
| **fact-check** | 验说法真假+推理，给校准置信度 | 这个说法能信几分 |
| adversarial-review | 红队找致命弱点 | 哪里会垮 |
| steel-man | 正反论证后做决定 | 想法/决定要不要做 |
| enhanced-hv-analysis | 系统研究出长报告 | 研究一个对象 |
| dual-layer-explanation | 两层讲懂概念 | 讲懂概念 |

## 依赖

- 联网搜索（WebSearch/WebFetch/arXiv）。无网时降级：事实标"未能联网核实"，推理链照做。核心无依赖。
