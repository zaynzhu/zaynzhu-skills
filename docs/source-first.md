# Source-First — 搜索可信度决策层

## 一句话

任何联网搜索先过本技能：官方域名三层发现（结构化数据直采 → 独立佐证 → 假官网负筛）+ 递归溯源穿透转载层 + GEO/SEO 垃圾快筛与五级源分级 + 独立交叉验证破循环印证，输出带来源分级与验证状态的答案，防 GEO/SEO 污染和以讹传讹。

## 设计理念

搜索结果被污染有三种典型形态：GEO/SEO 污染污染的是**排名**不是事实（官方服务器上的原始页面仍然干净）；以讹传讹让"多家口径一致"成为循环印证假象（看似多源，实则一个源头）；模型照单全收把结论外包给 SEO 排名。

核心信念：**只信源头，不信转发。** 溯源能穿透整个转发层，独立性判定能破循环印证，所以主干是递归溯源，快筛和降级只是护栏。

关键洞察：官方域名发现不能信搜索排名——前排"官网"可能正是 GEO 攻击的成果（实测：裸搜"防晒衣哪个牌子好 2026"，前 5 条全是榜单农场、零官方源，含"成立于20005年"的硬伤页）。

## 触发方式

说以下任意一句即可触发（凡联网搜事实信息，默认走本技能而非裸搜索）：

- "搜一下 / 查一下 / 查最新 / 找资料 / 联网搜 / 上网查"
- "官网是哪个 / 官方价格 / 官方参数 / 正品渠道 / 一手来源 / 首发通报"
- "网上信息太乱 / 以讹传讹 / 不知道信谁 / 别被垃圾信息污染"

**档位**：`--quick`（域名定位+快筛+提示，不自动溯源）/ 默认标准（关键结论自动轻量补验 1-2 次）/ `--deep`（全量溯源，重要决策用）。

## 基本用法

纯指令技能，零脚本零新依赖，按需复用：

- **Tavily 搜索**：`enhanced-tavily-search` 脚本（`--include-domains` 官方域定向、`--start-date/--end-date` 锁首发窗口、`--min-score` 降噪），需 `TAVILY_API_KEY`
- **WebFetch**：官网直达、页面本体深检、Wikidata P856 官网属性 API（不花搜索额度）
- **浏览器 MCP**：中文封闭生态（百度、微信搜一搜）、以图搜图反查（可选）

没有 TAVILY_API_KEY 也能跑（走 WebFetch/WebSearch/浏览器）；全无联网工具时输出手动验证指南，不罢工。

## 输出四件套

1. **结论**：正常回答，时效信息带明确日期；
2. **来源分级**：五级（官方一手 / 权威原创·转载 / 普通媒体 / UGC / 可疑农场），每级有可信用法（如 3 级只当线索、5 级不采用）；
3. **验证状态**：每条关键信息标（已溯源到官方 / 多源独立一致 / 单一来源未验证 / 来源冲突）；
4. **风险与缺口**：冲突并列、未核实清单、建议 --deep 的项。

日常泛搜索走**预警模式**：行内标注可疑项 + 一句风险提示，不写长篇审查报告。

## 边界与区分

- **enhanced-tavily-search**：裸搜索执行器之一。它管"怎么搜"，本技能管"搜什么、信什么"。
- **fact-check**：已有说法要验真 → fact-check（拆三层+推理链）；搜索阶段保障来源质量 → 本技能。溯源中发现用户在核一个说法 → 转 fact-check。
- **enhanced-hv-analysis**：深度研究报告，其搜索环节应先过本技能快筛与溯源。

## 已验证

- 迭代 1 基准评测（2026-08-31，5 查询 × 技能/基线对照，断言 19/19 vs 13/15）：增值集中在垃圾源降级标注、验证状态、交叉验证补强；数据发布/虚构品牌/无网降级类通用场景基线本来就强；tokens 约为基线 3.2 倍（标准档溯源成本，--quick 可省）。
- 独立自审五维度 PASS；冒烟测试实锤中文搜索污染基线（详见 `skills/source-first/` 内 references）。

## 适用场景

- 搜品牌/产品官方信息：官网、官方价格参数、正品渠道（假官网、竞价排名重灾区）
- 搜新闻/事件：官方通报、首发报道，识破旧闻混充和转述走样
- 搜技术资料：官方文档、原始论文、官方仓库（版本锚点）
- 日常泛搜索：自动预警层，快筛可疑结果、关键结论自动补验
