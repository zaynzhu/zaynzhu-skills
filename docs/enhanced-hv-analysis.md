# Enhanced HV-Analysis — 增强版横纵分析法

## 一句话

对产品/公司/人物/技术/行业/事件做一份可追溯的深度研究：纵轴追完整生命历程（诞生→转折成败→早期选择如何变成今天的能力/路径依赖/包袱），横轴在当下截面与最值得比较的对象做统一维度对比（强项/短板/独特性 + 为什么选它又为什么放弃它），两轴交汇判断未来 3 条路径（前提+预警信号），出 1-3 万字 PDF 报告。

## 设计理念

横纵分析法融合索绪尔历时-共时分析、社会科学纵向-横截面研究设计、商学院案例研究法与竞争战略分析。本增强版在原版框架上加了更锐利的分析刀和更严的证据纪律。

核心信念：**研究质量 = 信息质量 × 诚实度。** 所以既要多搜（信息质量），又要可追溯（诚实度）——每个结论就近标来源+日期，事实/推断/观点分开，冲突并列，搜不到写"暂未核实"。

## 相对原版 hv-analysis 的 6 处增强

1. **可追溯**作为原则 + 研究截止时间=执行当天
2. 纵向收口于：早期选择→**能力/路径依赖/包袱**
3. 横向收口于：**为什么选它 + 为什么放弃它**
4. 未来 **3 条路径 + 前提 + 预警信号**（不只三剧本）
5. 证据规则：**就近标注来源+日期、事实/推断/观点分开、冲突并列、"暂未核实"**
6. 输出顺序：**核心结论→关键时间线→横向对比表→详细分析→未来判断→仍待确认的问题**（结论先行）

## 触发方式

说以下任意一句即可触发：

- "横纵分析 / 横纵分析法"
- "深度研究 / 帮我研究一下 X / 调研一下 X"
- "竞品分析 / 帮我搞懂 X 怎么回事 / 帮我摸清楚 X"
- "做个 deep research / 系统研究一下这个产品/公司/人物/技术/行业/事件"

即使用户只说"帮我了解一下 XX"、"XX 是什么来头"，只要暗示要系统性深度研究（而非简单名词解释），也应触发。

**关键区分**：只要讲懂一个概念的机制（两层解释）→ dual-layer-explanation；要系统研究发展史+竞争格局（纵+横+报告）→ 本技能。不建议与原版 hv-analysis 同时安装（触发词重叠会撞车，建议二选一）。

## 工作流程

1. **前置准备**：明确研究对象（产品/公司/人物/技术/行业/事件）+ 研究截止时间=执行当天
2. **联网信息收集**：子 Agent 并行搜纵向/横向/补充，一手来源优先，学术类查 arXiv，充分性自检
3. **纵向分析**（6000-15000 字）：起源→演进→决策逻辑→阶段划分，收口于**路径依赖/能力/包袱**
4. **横向分析**（3000-10000 字）：判竞品场景 A/B/C + 说明为什么选它们，统一维度对比强项/短板/独特性，收口于**选择 vs 放弃**
5. **横纵交汇**（1500-3000 字）：历史→当下位置，未来 **3 路径 + 前提 + 预警信号**
6. **输出 + PDF**：按 6 段顺序输出，转 PDF

## 证据规则（核心纪律）

1. 一手来源优先（官方/Release/创始人推文 > 权威原创 > 转载；学术查 arXiv）
2. 重要结论就近标 `[来源，日期]`
3. 事实/推断/观点分开（推断标"据此推断"，观点用"我的判断是"）
4. 冲突并列 + 搜不到写"暂未核实"，绝不编造

## 输出顺序

核心结论 → 关键时间线 → 横向对比表 → 详细分析 → 未来判断 → 仍待确认的问题 → 信息来源 → 方法论说明

## 篇幅

全文 10,000-30,000 字（纵向 6000-15000 / 横向 3000-10000 / 交汇 1500-3000）。

## 依赖

- 联网搜索（WebSearch/WebFetch/arXiv）
- PDF 生成：`scripts/md_to_pdf.py`（WeasyPrint + markdown）。无 WeasyPrint 时降级只交付 Markdown。
- 写作风格指南、PDF 输出指南、结构 schema 在 `references/` 下。

## 与同类技能的区分

| 技能 | 做什么 | 何时用 |
|------|--------|--------|
| **enhanced-hv-analysis** | 纵+横系统研究+可追溯+出报告 | 系统研究一个对象的发展史和竞争格局 |
| dual-layer-explanation | 两层讲懂一个概念 | 讲懂概念机制 |
| reverse-deconstruction | 拆单个成品为什么好 | 学一个作品好在哪 |
| agentseo | 审计网站对 AI 友不友好 | 网站 agent 可读性 |
