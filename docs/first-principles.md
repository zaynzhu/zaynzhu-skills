# first-principles

第一性原理推导：把问题拆回最底层，区分四类（已确认的基本事实 / 习惯性接受却没验证的假设 / 真正想实现的目标 / 现实资源与约束），从基本事实提炼不可再分解的底层公理，放下行业惯例和现成方案，只从基本事实、目标和约束重新推导可行路径，最后输出原方案修补表面的部分、新路径、成立前提、验证第一步。

## 功能

- **三层推导结构**：拆解层（拆成四类）→ 公理层（从基本事实提炼底层公理）→ 重建层（从基本事实+目标+约束重新推导）
- **拆解层拆四类**：基本事实（要验）/ 习惯假设（要攻）/ 真正目标（要对齐）/ 资源约束（要纳入）——目标错则推导全废，约束从输入端纳入而非事后补
- **自动识别内容类型**：商业/产品、技术/架构、个人决策、行业分析，调整推导重点
- **公理判断标准**：由物理规律、数学逻辑或人类基本需求决定，而非历史选择；剔出伪装成公理的惯例
- **四件输出**：原方案修补表面的部分 / 重新推导的新路径 / 路径成立前提 / 验证第一步——让推导可验证可行动，不只是理论

## 依赖

- 无需任何外部 API 或脚本依赖，纯 prompt 级技能。

## 快速开始

```bash
# 触发 first-principles 技能
/first-principles

# 或直接说
"用第一性原理分析一下"
"从底层逻辑出发"
"重新想想这个问题"
"打破惯性思维"
```

## 适用场景

- 产品设计：重新审视用户真实需求
- 商业决策：挑战行业惯例和成本结构
- 技术选型：从问题本质约束出发选择方案
- 架构设计：突破现有范式的限制
- 个人选择：厘清真实目标和机会成本
- 行业分析：识别价值链的必要环节 vs 历史惰性

## 输出结构

1. **拆解层**：拆成四类——基本事实 / 习惯假设（重点攻击）/ 真正目标 / 资源约束
2. **公理层**：从基本事实提炼不可再分解的底层公理（通常 3-7 条），剔出伪装惯例
3. **重建层**：放下行业惯例，从基本事实+目标+约束重新推导，输出四件——原方案修补表面的部分、新路径（含完整逻辑链）、路径成立前提、验证第一步
