# first-principles

第一性原理推导：对任意问题、决策或方案，先穷举现有假设，找出真正不可再分解的底层公理，再从公理出发重新推导出无约束的新方案，打破「因为一直都这么做」的惯性思维。

## 功能

- **三层推导结构**：拆解层（穷举假设）→ 公理层（提炼底层事实）→ 重建层（从公理推导新方案）
- **自动识别内容类型**：商业/产品、技术/架构、个人决策、行业分析，调整推导框架
- **区分两类假设**：事实性假设（有依据）vs 惯例性假设（值得质疑）
- **公理判断标准**：由物理规律、数学逻辑或人类基本需求决定，而非历史选择

## 依赖

- 无需任何外部 API 或脚本依赖，纯 prompt 级技能。

## 快速开始

```bash
# 触发 first-principles 技能
/first-principles

# 或直接说
"用第一性原理分析一下"
"从底层逻辑出发"
"重新想想这个问题"
"打破惯性思维"
```

## 适用场景

- 产品设计：重新审视用户真实需求
- 商业决策：挑战行业惯例和成本结构
- 技术选型：从问题本质约束出发选择方案
- 架构设计：突破现有范式的限制
- 个人选择：厘清真实目标和机会成本
- 行业分析：识别价值链的必要环节 vs 历史惰性

## 输出结构

1. **拆解层**：穷举现有假设，区分事实性假设和惯例性假设
2. **公理层**：提炼不可再分解的底层事实（通常 3-7 条）
3. **重建层**：从公理出发推导新方案，展示完整逻辑链，列出与现状的核心差异

## 关联技能

- `adversarial-review`：侧重批判性审查，适合找问题和弱点
