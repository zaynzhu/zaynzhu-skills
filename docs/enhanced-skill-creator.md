# enhanced-skill-creator

Skill 全生命周期管理工具。

## 功能

从零创建、编辑优化、测试评测、打包交付——覆盖 Skill 从想法到成品的完整流程。

- 需求收集 → 草稿编写 → 自审 → 测试运行 → 评审反馈 → 迭代改进 → 描述优化 → 打包交付
- 内置 5 类技能模板库
- 多层次情境测试（L1 正常路径 / L2 边界用例 / L3 对抗用例）
- 描述优化流程；自动运行所需脚本未随本仓库提供

## 依赖

- 无必需工具（纯指令型 Skill）
- 可选：Python（执行另行取得并核实的辅助脚本）

本仓库提供主指令、评审指令和参考模板，未包含正文引用的 `scripts/`、`eval-viewer/`、`assets/`。使用自动聚合、查看器、描述优化或打包命令前，先核对对应工具是否存在；缺失时说明限制并采用等价流程，不宣称已运行这些工具。已验证的降级方式与证据边界见[评测经验](lessons/skill-evaluation-evidence.md)。

## 使用方式

直接告诉 AI 你想做什么：

```
帮我做个技能，用来……
把这个流程保存成技能
优化一下我的 skill
```

Skill 会自动判断你处于哪个阶段，从那里接手。

## 文件结构

```
enhanced-skill-creator/
├── SKILL.md          ← 主指令
├── agents/           ← 子 agent 指令
└── references/       ← 数据结构、写作模式和 5 类模板
```
