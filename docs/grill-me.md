# grill-me

`grill-me` 针对方案或设计进行刨根问底的访谈，遍历决策树的每个分支，直到您和 AI 达成**共识**。

## 功能

- **一次只问一个问题**并等待。它绝不会向您倾泻一堆问题（这会让人不知所措）。
- 如果某个问题可以通过阅读代码库来解决，它会去阅读代码库，而不是提问。
- 每个问题都会带有 AI 推荐的答案，这样您只需对提议做出反应，而不是面对空白的提示词。
- **无状态**：它不写入任何文件，也不留下任何工作区残留。它在任何地方都可以运行，唯一的产出是对话本身建立起来的更清晰的理解。

## 依赖

- 无需任何外部 API 或脚本依赖，纯 prompt 级技能。

## 快速开始

```bash
# 触发 grill-me 技能
/grill-me
```

## 适用场景

在您准备开始编码构建之前，当方案感觉大概正确，但您能感觉到其中隐藏着尚未确定的决策时使用。使用它将这些模糊地带逼出并加以解决。

如果您希望在提问的同时留下 ADR（架构决策记录）和 `CONTEXT.md` 术语表，请改用 `grill-with-docs`（如果已安装）。

## 关联与区别

`grill-me` 是一个随时可用的独立工具，用于在构建前对计划进行压力测试。它是指向底层 `grilling` 技能的无状态、用户触发入口。

- 它与 `grill-with-docs` 的区别在于：后者是**有状态的**，会以 ADR 和术语表的形式持久化记录决策，而 `grill-me` 是**无状态的**，仅在会话中进行对齐。
- 如果您希望在提问结束后自动生成 Spec 或 PRD，可以后续将控制权移交给 `/to-prd`，它将对齐后的理解合成为 PRD，无需重复访谈。
