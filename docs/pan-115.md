# pan-115 — 115 网盘助手

## 解决什么问题

让 AI agent 直接操作 115 网盘：扫码登录获取 cookies、浏览目录、搜索文件、添加离线下载任务、查看任务状态，不需要用户手动开浏览器或客户端复制粘贴。

基于 [p115client](https://github.com/ChenyangGao/p115client) SDK，通过 cookies 认证调用 115 官方接口。

## 功能一览

| 功能 | 命令 | 依赖 |
|------|------|------|
| 扫码登录（生成二维码 → 115 App 确认 → 自动保存 cookies） | `python scripts/login.py --no-open` | 仅标准库 |
| PowerShell 备用扫码登录（Windows） | `pwsh -File scripts/get_cookie.ps1 -NoOpen` | PowerShell 7 |
| 手动保存/验证 cookies | `python3 scripts/save_cookies.py --stdin` | 仅标准库 |
| 测试连接（账户信息、存储空间、根目录预览） | `python3 scripts/test_connection.py` | p115client |
| 浏览目录 / 搜索文件 | `python3 scripts/browse.py [目录ID]`、`--search 关键词` | p115client |
| 添加离线下载（磁力/ed2k/HTTP） | `python3 scripts/offline_download.py '<URL>'` | p115client |
| 查看离线任务 / 配额 / 下载目录 | `python3 scripts/offline_download.py --list` / `--quota` / `--path` | p115client |

## 依赖与首次安装

脚本分两类：

- **扫码登录、cookies 保存**：零依赖，Python 标准库即可，Windows / macOS / Linux 通用
- **业务功能**（浏览/搜索/离线下载/测试连接）：固定 Python 3.12 + 锁定版本的 p115client（`requirements.txt` 锁定全部传递依赖）

首次使用业务脚本前，在技能目录创建私有 `.venv`：

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt   # Windows 用 .venv\Scripts\python.exe
```

脚本检测到技能目录下的 `.venv` 后会自动切换到该环境运行，不需要手动指定解释器。

## Cookies

- 标准路径：`~/.115-cookies`，单行格式 `UID=xxx; CID=xxx; SEID=xxx; KID=xxx`
- cookies 过期后重新扫码即可；脚本会用 `Path` 对象初始化客户端，续期后可自动写回文件
- 建议保持 `chmod 600` 权限，仅本人可读写

## Agent 二维码展示约定

扫码登录脚本会同时输出多种机器可读标记（`LOGIN_QR_JSON` / `QR_IMAGE_PATH` / `QR_FILE_URI` / `QR_REMOTE_URL` / `QR_MARKDOWN`），兼容 Claude Code、Codex、OpenClaw、Hermes 和普通 CLI agent。agent 监听 stdout，看到标记后立即用自己支持的方式把二维码展示给用户，并保持登录进程运行等待扫码确认。详见 `skills/pan-115/SKILL.md` 的「Agent 兼容约定」。

## 注意事项

- **tv cookies 与 web 文件接口登录态可能不通**：默认用 `tv` 扫码；浏览/搜索接口如果返回"请先登录"，改用 `python scripts/login.py --app web --no-open` 重扫
- **服务器 IP 必须用 `fs_files_aps()`**：`fs_files()` 从服务器 IP 调用会被 115 拦截返回 405
- **115 API 字段名是缩写**：`n`=文件名、`s`=大小、`cid`=目录 ID，详见 SKILL.md 的 Pitfalls 表
- 扫码状态轮询间隔默认 2 秒（`--poll-interval` 可调），符合本项目外部 API 调用频率规范
