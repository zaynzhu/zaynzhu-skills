# Dual-Layer Explanation — 双层解释法

## 一句话

把一个概念分两层解释——小白版（生活化语言 + 具体例子）和专业版（准确术语 + 核心机制 + 适用边界 + 常见误解），再出三件套：小白说法↔专业术语对应、最容易理解错的地方、3 个检验是否真懂的检查问题。专治"好像懂了"。

## 设计理念

"把我当小学生解释"确实容易听懂，但容易停在"好像懂了"——类比记住了，真正的机制还是一团雾。因为单层小白解释只给了一个直觉钩子，没给机制本身。

本技能的解法：**解释两遍，再搭桥。** 小白版给钩子，专业版给机制，三件套把两层连起来并主动拆掉"好像懂了"的陷阱。

核心信念：**听懂类比 ≠ 理解机制。** 只有能把类比每一部分映射回机制对应部分、并知道类比在哪里失效，才算真懂。

## 触发方式

说以下任意一句即可触发：

- "双层解释 / 分两层解释一下"
- "从小白和专家两个角度解释"
- "我想学习的是：【X】"
- "把我当小学生解释但别只讲类比"
- "我是个学习能力很强的智障，帮我搞懂"
- "我想真正搞懂 / 学明白 X"
- "解释一下 X / 什么是 X"（带想真正理解的意图时）

即使用户只是想学懂一个概念，没有用上述原话，也应触发。

**不触发**：用户想产出内容给别人看（写文章/教程）、只是查事实（作者是谁、怎么安装）、或要做其他技能的事（论证/推导/审查）。

## 工作流程

### 第一层 · 小白版

生活化语言 + 一个具体到本概念的例子，让零基础的人跟着走一遍看到概念怎么起作用。例子必须能映射机制，不是万能类比（"像一个盒子"）。不在小白版偷塞专业术语。

### 第二层 · 专业版

准确术语讲清四件：
- **核心机制**：补上小白版没给的"怎么运作"
- **适用边界**：什么条件下管用 / 不管用
- **常见误解**：主动排雷，具体到"有人以为 A 其实 B 因为 C"

### 收尾三件套（灵魂）

1. **小白说法 ↔ 专业术语对应**：对照表，左小白右专业，加"对应机制哪一步"。这是两层之间的桥，让你用直觉反推机制。
2. **最容易理解错的地方**：主动指出类比在哪里失效、机制哪里反直觉。不点出来用户会把类比当机制，在失效处继续套用——这就是"好像懂了"的根源。
3. **3 个检查问题**：逼主动推理验证理解。好问题测迁移（换场景用机制推）、测边界（条件还管用吗）、测误解（错误说法错在哪），各一种，不测复述/定义/背诵。

## 输出示例

```
## 🧒 第一层 · 小白版
> [一句话点明理解的 X]
[生活化语言 + 具体例子走一遍]

## 🎓 第二层 · 专业版
**核心机制**：[…]
**适用边界**：[…]
**常见误解**：[…]

## 🌉 收尾三件套
**1. 小白说法 ↔ 专业术语**
| 小白说法 | 专业术语 | 对应机制 |
| … | … | … |

**2. 我最容易理解错的地方**
> [类比失效点 / 反直觉处]

**3. 检查你是否真懂的 3 个问题**
1. [迁移型]
2. [边界型]
3. [误解型]
> 答完不确定就发给我，我帮你判断卡在哪。
```

## 力度控制

- 默认：两层讲足，三件套做全
- `--quick`：压缩篇幅，快速过一遍
- `--deep`：专业版加深，适用边界和常见误解展开（备考/硬核）

## 与同类技能的区分

| 技能 | 做什么 | 何时用 |
|------|--------|--------|
| **dual-layer-explanation** | 分两层把概念讲透 + 三件套验证 | 已知想学什么，要真搞懂机制 |
| socratic-questioning | 追问收敛出真问题 | 说不清自己想问什么 |
| first-principles | 还原公理重新推导 | 打破惯性、从底层重构 |
| steel-man | 正反论证后做决定 | 已有想法，先想透正反再定 |

## 依赖

无。纯思维框架，任何环境可用。
