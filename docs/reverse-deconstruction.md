# Reverse Deconstruction — 反向拆解

## 一句话

拿到一个优秀范例（产品页/网页/方案/流程/数据看板等成品），先用一句话说它解决了什么问题，再反向拆解它为什么有效（五点分析），最后给三件套：可复用规律 + 应用清单 + 一个最值得先试的小练习。

## 设计理念

看到好作品，第一反应是"好牛"。但**赞美教不会你任何东西**——"UX 好"、"设计干净"全对但没法照着做。

本技能不描述"好在哪"，而是拆**为什么有效**：它为服务谁、在什么约束下、在哪个岔路口选了 A 而平庸版本选了 B，所以才拉开差距。这个"选择 + 为什么在这个目标下更优"才是能迁移的。

核心信念：**"它很好"没用；"它在 X 目标下、因 Y 约束、选了 Z 而不是 W，所以赢了"才有用。**

还要防 cargo-cult：范例里有些东西是它的目标/情境决定的，照搬会错。所以必须切分"可迁移规律"和"只适合本案例的细节"。

诚实是底线：范例其实平庸/有硬伤时，先点哪里不行，再拆可取之处，不硬夸。

## 触发方式

说以下任意一句即可触发：

- "反向拆解 / 拆解一下这个范例好在哪"
- "分析它为什么有效"
- "我想学这个作品好在哪 / 学到它的精髓"
- "拆解这个产品页 / 网页 / 方案 / 看板"
- "逆向工程一下它 / 这个设计为什么好"

即使用户只是贴了个成品问"这个好在哪"、"为什么做得好"，也应触发。

**不触发**：审计网站对 AI 友不友好（agentseo）、深度研究产品/公司（hv-analysis）、批判找漏洞含代码审查（adversarial-review/code-review）、讲懂概念（dual-layer-explanation）。

## 工作流程

### 准备

- **输入**：默认粘贴内容；给 URL 且有浏览器 MCP 则自动抓取渲染后内容，无浏览器则降级请用户粘贴关键内容。
- **最少必要提问**：没给范例必须问；没给"想学会什么"默认拆整体；范例模糊不反问，用合理理解开始并点明。

### 诚实性闸门

范例真平庸/有硬伤 → 先指出哪里不行，再只拆可取之处。硬夸平庸范例会产出廉价规律。

### 第一步：一句话

- **它解决的问题**：为谁、在什么情境下、解决什么痛点（定锚，后面判断都挂这上面）
- **它为什么有效**：核心机制一句话

### 第二步：五点分析

1. **服务谁 / 目标**：具体受众 + 诉求（这是后面四点的尺子）
2. **结构 / 流程**：按成品类型看骨架——网页看信息架构/交互、方案看论证结构、流程看步骤/决策点、看板看指标/视觉编码
3. **拉开质量差距的关键选择**（心脏）：每个选择写"平庸做法 vs 它怎么选 + 为什么在它的目标下更优"。禁空形容词，每个"好"必须配具体选择
4. **完成标准**：这类成品"做好"的及格线 + 范例在哪超标/达标
5. **可迁移 vs 只适合本案例**：切两栏，防 cargo-cult，不可迁移的要说明为什么

### 第三步：三件套

1. **3-5 条可复用规律**：每条 = 原则 + 为什么 + 什么条件下用，不凑数
2. **应用清单**（复刻到自己项目）：可执行步骤；已知用户场景就落地，未知用 `[换成你的场景]` 占位并留挂钩，不阻塞
3. **一个最值得先试的小练习**：15-30 分钟可完成、能立刻验证一条规律、具体到"拿什么做什么看什么"。只给一个

## 输出示例

```
## 🎯 一句话
**它解决的问题**：[为谁/情境/痛点]
**它为什么有效**：[机制一句话]

## 🔍 五点分析
1. 服务谁/目标：[…]
2. 结构/流程：[…]
3. 拉开质量差距的关键选择：
   - [选择]：平庸是 ___，它选了 ___，在它的目标下更优因为 ___
4. 完成标准：[…]
5. 可迁移 vs 只适合本案例：
   - 可迁移：[…]
   - 只适合本案例：[…]（为什么不能迁移：___）

## 📦 三件套
1. 可复用规律（3-5 条）：[原则——为什么——什么条件用]
2. 应用清单：- [ ] 步骤…  > [未知场景] 告诉我你在做什么，我落地成具体步骤
3. 最值得先试的小练习：> [15-30 分钟可完成的具体动作]
```

范例平庸时最前面加 `## ⚠️ 先说哪里不行`。

## 力度控制

- 默认：五点全拆、三件套做全、最大诚实
- `--quick`：一句话 + 关键选择 3 条 + 规律 3 条 + 一个练习
- `--deep`：每个关键选择展开平庸版本完整分析

## 与同类技能的区分

| 技能 | 做什么 | 何时用 |
|------|--------|--------|
| **reverse-deconstruction** | 拆解成品为什么有效 + 提炼可迁移规律 | 学一个好作品好在哪、怎么用上 |
| dual-layer-explanation | 分两层讲懂一个概念 | 讲懂概念 |
| agentseo | 审计网站对 AI 智能体可读性 | 网站对 agent 友不友好 |
| hv-analysis | 产品/公司横纵深度研究 | 深度研究一个产品/公司 |
| adversarial-review | 红队批判找致命弱点 | 找漏洞（含代码审查） |

## 依赖

无（核心无依赖）。URL 抓取可选——有浏览器 MCP（chrome-devtools/playwright/superpowers-chrome）时自动抓，无则降级为用户粘贴。
